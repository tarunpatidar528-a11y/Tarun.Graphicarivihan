# Arivihan Graphic Gallery

Modular static gallery for Arivihan graphics.

## Sections
- Thumbnail
  - Add Folder is available only inside Thumbnail
- Social Media Post
- Google Ads
- Banner
- Pamplet
- Community Post
- Background Reference

## Project structure
- `index.html` — main website
- `css/style.css` — complete design
- `js/app.js` — main gallery system
- `js/folders.js` — folder system
- `js/upload.js` — image upload and filename tags
- `js/search.js` — search/filter
- `js/viewer.js` — fullscreen preview
- `js/storage.js` — browser storage

AI/OCR/Tesseract scanning has been removed.
